## Understanding `Object.is`  (optional)
Object.is() — это метод в JavaScript, который сравнивает два значения на точное равенство, не выполняя при этом преобразование типов. В отличие от оператора `===`, `Object.is()` корректно обрабатывает `NaN` и различает +0 и -0. Это полезно в ситуациях, когда необходимо строгое сравнение значений без каких-либо преобразований.

## Differences between `let`, `var`, and `const`

`var` объявляет переменную с функциональной областью видимости. Переменные, объявленные с помощью var, могут быть переопределены и повторно объявлены в той же области видимости.

`let` вводит блочную область видимости. Переменные, объявленные с помощью let, не могут быть повторно объявлены в той же блочной области, но их значение можно изменить.

`const` также имеет блочную область видимости, но объявленные с его помощью переменные должны быть инициализированы при объявлении и не могут быть изменены впоследствии.

## Exploring the Temporal Dead Zone

**Временная мёртвая зона (TDZ)** — это период в блоке кода, где переменные, объявленные с помощью let или const, недоступны до момента их объявления. Это предотвращает доступ к переменным до их инициализации, что помогает избежать ошибок, связанных с неинициализированными переменными.

## Concepts of Hoisting

**Хостинг** — это механизм в JavaScript, при котором объявления переменных и функций перемещаются в верхнюю часть своей области видимости до выполнения кода. Это означает, что переменные и функции можно использовать до их объявления в коде, но их значения будут неопределёнными до момента фактического объявления и инициализации.

## The role of polyfills

**Полифилы** — это фрагменты кода, которые эмулируют функциональность современных браузеров в более старых версиях, где эта функциональность отсутствует. Они позволяют использовать новые возможности JavaScript и других веб-технологий в устаревших браузерах, обеспечивая совместимость и улучшая пользовательский опыт.

## Differences and uses of arrow functions, function expressions, and function declarations

**Стрелочные функции (arrow functions)** — это краткий синтаксис для определения анонимных функций. Они не создают собственного `this`, arguments, super или new.target, что делает их удобными для работы с замыканиями и контекстом.

**Функциональные выражения (function expressions)** — это объявления функций, которые могут быть присвоены переменным и переданы как аргументы другим функциям. Они могут иметь имя или быть анонимными.

**Объявления функций (function declarations)** — это традиционный способ объявления функций с именем, которое доступно в области видимости, где функция объявлена.
Каждый из этих способов имеет свои особенности и используется в зависимости от контекста и требований задачи.

## Global scope vs. functional scope

**Глобальная область видимости (global scope)** — это область, в которой переменные и функции доступны из любого места в коде. Переменные, объявленные вне функций или блоков, имеют глобальную область видимости.

**Функциональная область видимости (functional scope)** — это область видимости, ограниченная функцией. Переменные и функции, объявленные внутри функции, доступны только внутри этой функции.

Понимание различий между глобальной и функциональной областями видимости важно для управления доступом к данным и предотвращения конфликтов имён.

## Variable visibility areas

**Области видимости переменных** определяют, где переменные доступны в коде. В JavaScript существуют глобальная, функциональная и блочная области видимости. Понимание областей видимости помогает избежать ошибок и улучшить структуру кода.

## Working with nested scopes

**Вложенные области видимости** возникают, когда одна область видимости (например, блок или функция) находится внутри другой. Переменные во внутренних областях видимости могут скрывать переменные с теми же именами во внешних областях, но могут обращаться к ним через механизмы, такие как замыкания.

## Defining function parameters

**Параметры функции** — это значения, которые передаются функции при её вызове. В JavaScript параметры могут быть объявлены с использованием function объявления, функциональных выражений или стрелочных функций. Параметры могут иметь значения по умолчанию, а также могут быть переданы как аргументы при вызове функции.

## Differences in parameters passing by value and by reference

**Передача по значению (pass by value)** — это механизм, при котором копия значения переменной передаётся функции. Изменение параметра внутри функции не влияет на исходное значение.

**Передача по ссылке (pass by reference)** — это механизм, при котором ссылка на объект передаётся функции. Изменение параметра внутри функции влияет на исходный объект.

В JavaScript все примитивные типы передаются по значению, а объекты — по ссылке.

## Handling a dynamic amount of function parameters

Для работы с динамическим количеством параметров в JavaScript можно использовать следующие подходы:

- **Аргументы (arguments object)** — специальный объект, который содержит все аргументы, переданные функции.

- **Оператор rest `(...)`** — позволяет собирать оставшиеся аргументы в массив, что упрощает работу с переменным количеством параметров.

## Understanding context and lexical environments

**Контекст выполнения (execution context)** в JavaScript — это абстракция, которая представляет среду, в которой выполняется код. Он включает в себя информацию о переменных, функциях и значениях `this`. Каждый раз, когда выполняется функция или блок кода, создаётся новый контекст выполнения.

**Лексическая среда (lexical environment)** — это структура данных, которая связывает идентификаторы (переменные и функции) с их значениями. Она определяется на этапе компиляции и остаётся неизменной во время выполнения. Лексическая среда состоит из двух частей: окружения (environment record), где хранятся переменные и функции, и ссылки на внешнюю лексическую среду (outer environment reference), что позволяет доступ к переменным из внешних областей видимости.

## Differences between scope and context

**Область видимости (scope)** определяет доступность переменных и функций в разных частях кода. В JavaScript существуют функциональная и блочная области видимости. Функциональная область видимости ограничивается функцией, а блочная — блоком кода `{}`.

**Контекст выполнения** более широкий термин, который включает в себя не только область видимости, но и значения `this`, а также другие аспекты выполнения кода. Контекст определяет, как код взаимодействует с окружающей средой и как обрабатываются переменные и функции.

## The mechanism of lexical environment traversal

**Механизм обхода лексических сред** позволяет функциям иметь доступ к переменным из своих родительских областей видимости. Когда функция обращается к переменной, JavaScript сначала ищет её в своей собственной лексической среде. Если переменная не найдена, поиск продолжается в родительской лексической среде и так далее, пока не будет найдена переменная или не достигнет глобальной лексической среды.

## Connection between function and its lexical environment

Функция в JavaScript имеет связь со своей лексической средой, в которой она была определена. Это означает, что функция может иметь доступ к переменным и функциям из своей родительской области видимости, даже если они были определены до создания функции. Это свойство позволяет создавать замыкания, которые могут сохранять состояние между вызовами функции.

## `this` in functions

`this` в JavaScript — это специальный идентификатор, который ссылается на объект, в контексте которого функция была вызвана. Значение `this` определяется во время выполнения и зависит от того, как функция была вызвана.

## Reference Type & losing `this`

При работе с объектами и функциями важно учитывать, что `this` может измениться в зависимости от контекста вызова функции. Если функция, которая использует `this`, присваивается другой переменной или передаётся как обратный вызов, `this` может потерять связь с исходным объектом. Это может привести к неожиданным результатам.

## Understand difference between function and method

**Функция** — это блок кода, который выполняет определённую задачу и может быть вызван из разных мест программы. Функции могут быть объявлены с помощью _function declaration_, _function expression_ или _arrow functions_.

**Метод** — это функция, которая связана с объектом и может быть вызвана через этот объект. Методы обычно используются для работы с данными объекта и изменения его состояния.

## Understand how `this` works, realize `this` possible issues

`this` работает по-разному в зависимости от того, как функция была вызвана:

- Если функция вызвана как метод объекта, `this` будет ссылаться на этот объект.
- Если функция вызвана как самостоятельная функция, this будет ссылаться на глобальный объект (в строгом режиме — undefined).
- Если функция вызвана с использованием `call`, `apply` или `bind`, `this` можно явно задать.

Возможные проблемы с `this` включают потерю контекста при передаче функций как обратных вызовов или при использовании их в качестве обработчиков событий.

## Manage `this`

Для управления `this` можно использовать следующие подходы:
- `call` и `apply` позволяют явно задать `this` при вызове функции.
- `bind` создаёт новую функцию, у которой `this` привязан к указанному значению.

## Be able to replace `this` value

Значение `this` можно заменить с помощью `call`, `apply` или `bind`. Например:

```javascript
function greet() {
  console.log(`Hello, ${this.name}!`);
}

const person = { name: 'Alice' };
greet.call(person); // Выведет "Hello, Alice!"

```

## Be able to use `call` and `apply` Function built-in methods

`call` и `apply` — это методы, которые позволяют вызывать функцию с указанным значением `this` и аргументами. Разница между ними заключается в том, как передаются аргументы:

- `call` принимает аргументы по отдельности.
- `apply` принимает массив аргументов.

Пример использования `call`:

```javascript
function sum(a, b) {
  return a + b;
}

console.log(sum.call(null, 2, 3)); // Выведет 5
```

Пример использования `apply`:

```javascript
function sum(a, b) {
  return a + b;
}

console.log(sum.apply(null, [2, 3])); // Выведет 5
```

## Know how to bind `this` scope to function

`bind` — это метод, который создаёт новую функцию с привязанным значением this. Новая функция будет всегда использовать указанное значение `this`, независимо от того, как она была вызвана.

Пример использования `bind`:

```javascript
function greet() {
  console.log(`Hello, ${this.name}!`);
}

const person = { name: 'Bob' };
const greetBob = greet.bind(person);
greetBob(); // Выведет "Hello, Bob!"
```

## Binding, binding one function twice

Можно привязать функцию к разным значениям `this` несколько раз, создавая новые функции с разными контекстами. Это позволяет использовать одну и ту же функцию в разных контекстах без изменения её исходного поведения.

Пример:

```javascript
function greet() {
  console.log(`Hello, ${this.name}!`);
}

const person1 = { name: 'Charlie' };
const person2 = { name: 'Diana' };

const greetCharlie = greet.bind(person1);
const greetDiana = greet.bind(person2);

greetCharlie(); // Выведет "Hello, Charlie!"
greetDiana();   // Выведет "Hello, Diana!"
```

## Function default parameters

Параметры по умолчанию в JavaScript позволяют задать значения для параметров функции, если они не были переданы при вызове функции. Это упрощает код и делает его более читаемым.

Пример:
```javascript
function greet(name = 'Anonymous') {
  console.log(`Hello, ${name}!`);
}

greet(); // Выведет "Hello, Anonymous!"
greet('Alice'); // Выведет "Hello, Alice!"
```

## Using spread operator `...` for function arguments

Оператор spread `...` позволяет развернуть массив или объект в отдельные аргументы функции. Это удобно при работе с функциями, которые принимают переменное количество аргументов.

Пример:
```javascript
function sum(a, b, c) {
  return a + b + c;
}

const numbers = [1, 2, 3];
console.log(sum(...numbers)); // Выведет 6
```

## Comparing arguments and rest parameters

**arguments** — это специальный объект, который содержит все аргументы, переданные функции. Он доступен во всех функциях и позволяет работать с переменным количеством аргументов.

**rest parameters** — это синтаксис, который позволяет собирать оставшиеся аргументы в массив. Он более удобен и читаем по сравнению с arguments.

Пример:
```javascript
function sum(...numbers) {
  return numbers.reduce((acc, curr) => acc + curr, 0);
}

console.log(sum(1, 2, 3, 4)); // Выведет 10
```

## Array concatenation with spread operator

Оператор spread `...` можно использовать для объединения массивов.

Пример:
```javascript
const array1 = [1, 2, 3];
const array2 = [4, 5, 6];
const combinedArray = [...array1, ...array2];

console.log(combinedArray); // Выведет [1, 2, 3, 4, 5, 6]
```

## Destructuring assignments for variables and function arguments

**Деструктуризация** позволяет извлекать значения из массивов и объектов и присваивать их переменным. Это делает код более кратким и читаемым.

```javascript
console.log(age); // Выведет 25
```

## Understanding the Document Object Model (DOM)

**DOM (Document Object Model)** — это программный интерфейс, который представляет HTML-документ в виде иерархической структуры объектов. Каждый объект в этой структуре соответствует элементу HTML-документа.

## Types of DOM Events

DOM поддерживает различные типы событий, такие как:

- Мышиные события: `click`, `mouseover`, `mouseout`.
- Клавиатурные события: `keydown`, `keyup`, `keypress`.
- События формы: `submit`, `input`, `change`.

## Working with Mouse and Keyboard Events

Обработчики событий для мыши и клавиатуры можно прикрепить к элементам DOM с помощью `addEventListener()`.

Пример:
```javascript
document.addEventListener('click', event => {
  console.log('Clicked!');
});
```

## Handling Form and Input Events

События форм и ввода можно обрабатывать аналогично другим событиям.

Пример:
```javascript
const input = document.querySelector('input');
input.addEventListener('input', event => {
  console.log(event.target.value);
});
```

## Event Listeners
Event Listeners в JavaScript позволяют прикреплять функции-обработчики к событиям элементов DOM. Метод addEventListener() принимает два обязательных аргумента: строку с названием события (например, 'click') и функцию, которая будет выполняться при возникновении этого события.

Пример:
```javascript
const button = document.querySelector('button');
button.addEventListener('click', function() {
 console.log('Button was clicked!');
});
```

## Event Phases and their differences

Существует три фазы распространения события в DOM:

- **Capturing phase (фаза захвата)** — событие проходит от корневого элемента вниз к целевому элементу.
- **Target phase (целевая фаза)** — событие достигает целевого элемента.
- **Bubbling phase (фаза всплытия)** — событие распространяется от целевого элемента вверх по DOM-дереву к корневому элементу.

Разница между фазами заключается в порядке, в котором обработчики событий вызываются при распространении события.

## Custom events (optional)
Пользовательские события в JavaScript можно создавать с помощью объекта CustomEvent. Это позволяет разработчикам определять собственные события, которые могут быть запущены программно.

Пример:
```javascript
const event = new CustomEvent('myEvent', { detail: { message: 'Hello!' } });
document.dispatchEvent(event);
```

## Event propagation cycle

Цикл распространения события в DOM начинается с корневого элемента и проходит через все его потомков, пока не достигнет целевого элемента. Затем событие распространяется обратно к корневому элементу, вызывая обработчики событий на каждом этапе.

## Stopping event propagation

Чтобы остановить распространение события, можно использовать метод `stopPropagation()` в обработчике события. Это предотвратит дальнейшее распространение события по DOM-дереву.

Пример:
```javascript
function handleClick(event) {
 event.stopPropagation();
 console.log('Propagation stopped!');
}
```

## Preventing default browser behavior

Метод `preventDefault()` позволяет предотвратить стандартное поведение браузера для события. Например, можно предотвратить переход по ссылке при клике.

Пример:
```javascript
const link = document.querySelector('a');
link.addEventListener('click', function(event) {
 event.preventDefault();
 console.log('Default behavior prevented!');
});
```

## Event delegation and its pros/cons

**Делегирование событий** — это техника, при которой обработчик события прикрепляется не к каждому дочернему элементу, а к их общему родителю. Это позволяет упростить код и улучшить его производительность.

_Плюсы_:

- Уменьшение количества обработчиков событий.
- Возможность обработки событий для динамически добавляемых элементов.

_Минусы_:

- Может потребоваться дополнительная логика для определения целевого элемента.
- Может быть менее интуитивно понятно для начинающих разработчиков.

## Usage of `setTimeout` / `setInterval`

`setTimeout()` и `setInterval()` — это функции для организации отложенных и периодических вызовов функций соответственно.

`setTimeout(function, delay)` вызывает функцию один раз через указанный интервал времени.
`setInterval(function, delay)` вызывает функцию периодически с указанным интервалом.

Пример:
```javascript
const timeoutId = setTimeout(function() {
 console.log('This will run after 2 seconds');
}, 2000);

const intervalId = setInterval(function() {
 console.log('This will run every 1 second');
}, 1000);
```

## Clearing timers with `clearTimeout` / `clearInterval`

Для отмены отложенных или периодических вызовов можно использовать функции `clearTimeout()` и `clearInterval()`.

## Differences between LocalStorage, SessionStorage, and Cookies

- **LocalStorage** — хранилище данных, которое сохраняется между сеансами браузера. Данные хранятся в браузере и доступны для всех вкладок и окон с одного домена.
- **SessionStorage** — хранилище данных, которое сохраняется только в течение сеанса браузера. Данные хранятся в браузере и доступны только для одной вкладки или окна с одного домена.
- **Cookies** — текстовые файлы, которые хранятся на компьютере пользователя и могут быть отправлены вместе с HTTP-запросами. Они имеют срок истечения и могут быть настроены на отправку только по защищённым соединениям.

## Working with the Date object

Объект `Date` в JavaScript представляет дату и время. Его можно использовать для получения текущей даты, установки определённой даты, выполнения арифметических операций с датами и форматирования даты и времени.

Пример:
```javascript
const now = new Date();
console.log(now.getFullYear()); // Текущий год
console.log(now.getMonth()); // Текущий месяц (0-11)
console.log(now.getDate()); // Текущий день месяца
```

## Timezones and Internationalization in JavaScript (Intl)

**Международный API (Intl)** в JavaScript предоставляет инструменты для локализации и интернационализации приложений. Он включает в себя форматирование дат, чисел и валют в соответствии с региональными настройками.

Пример:
```javascript
const date = new Date();
const options = { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' };
const formattedDate = new Intl.DateTimeFormat('ru-RU', options).format(date);
console.log(formattedDate); // Форматированная дата на русском языке
```

## Understanding and applying KISS, DRY, and YAGNI principles
- **KISS** (Keep It Simple, Stupid) — принцип, который призывает к простоте и избеганию излишней сложности в коде.
- **DRY** (Don’t Repeat Yourself) — принцип, который гласит, что каждый фрагмент кода должен иметь единственное, неизбыточное представление в системе.
- **YAGNI** (You Aren’t Gonna Need It) — принцип, который советует не добавлять функциональность, которая не требуется в данный момент, чтобы избежать ненужной сложности.
